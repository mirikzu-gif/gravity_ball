# Gravity Ball Game

Игра с упругим мячом, управляемым стрелками, который преодолевает препятствия с помощью реалистичной физики.

## Структура проекта

```
gravity_ball/
├── src/                          # Исходный код
│   ├── entities/                 # Игровые сущности
│   │   ├── __init__.py
│   │   ├── ball.py              # Класс мяча
│   │   ├── obstacle.py          # Класс препятствий
│   │   └── platform.py          # Класс платформ
│   ├── utils/                    # Утилиты и настройки
│   │   ├── __init__.py
│   │   ├── config.py            # Конфигурация и константы
│   │   ├── physics.py           # Физические утилиты
│   │   └── level.py             # Генерация уровней
│   └── __init__.py
├── game.py                      # Оригинальная версия игры
├── game_refactored.py           # Реорганизованная версия
├── requirements.txt             # Зависимости
└── README.md                    # Документация
```

## Управление

- **Стрелки** - движение мяча
- **Пробел (зажать)** - зарядка прыжка
- **Отпускание пробела** - выполнение прыжка

## Особенности

- Реалистичная физика с гравитацией и сопротивлением воздуха
- Зависимость высоты прыжка от времени зарядки
- Различные материалы поверхностей с разными свойствами
- Автоматическая зарядка прыжка при зажатом пробеле

## Запуск

```bash
# Активация виртуальной среды
source venv/bin/activate

# Запуск игры
python game.py
```

### Быстрый запуск
```bash
source venv/bin/activate && python game.py
```

## Зависимости

- pygame 2.6.1
- pymunk 7.2.0

## Архитектура

### Сущности (entities/)
- **Ball** - управляемый игроком мяч с реалистичной физикой
- **Obstacle** - статические препятствия (камень)
- **Platform** - платформы для прыжков (дерево)

### Утилиты (utils/)
- **config.py** - все константы и настройки игры
- **physics.py** - физические функции и утилиты
- **level.py** - генерация игровых уровней

### Материальная система

Каждый объект имеет свойства материала:
- **Мяч**: упругость 1.5, трение 0.3, масса 5
- **Камень**: упругость 0.3, трение 0.8
- **Дерево**: упругость 0.5, трение 0.9
